## 🐕‍🦺 About the Project

**Petco** is a seasonal **pet care campaign website** focused on **winter services** for pets.  
It helps pet owners access essential **grooming, vet checkup, and care services** while promoting healthy, happy pets during cold weather.

> ❄️ *Because pets deserve warmth, comfort, and care all winter long.*

---

## 🎯 Purpose

This project raises **awareness for winter-specific pet care** while serving as a modern **React + Firebase** demonstration.  
It’s built to highlight responsive design, smooth animations, and clean React architecture.

---

## ✨ Features

✅ **Winter Pet Care Tips** – Quick seasonal advice for pet owners  
🐶 **Service Listings** – Grooming, accessories, and vet services  
👨‍⚕️ **Vet Expert Section** – Meet certified professionals  
🔐 **Firebase Authentication** – Email/Password + Google login  
🖼️ **Swiper.js Hero Carousel** – Interactive banner slider  
💫 **AOS Animations** – Smooth on-scroll fade and zoom effects  
⚡ **Toast Notifications** – Success/error feedback via `react-hot-toast`  
📱 **Fully Responsive** – Optimized for all devices  
🎨 **Tailwind + DaisyUI** – Fast, modern UI styling
